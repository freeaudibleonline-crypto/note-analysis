# 因果推定には使用不可

このディレクトリのコードと出力には**実装上の誤りが含まれている**。
削除せず保存しているのは、記事および `docs/technical_note.md` に記した
監査を第三者が再現できるようにするためである。

**ここにある推定値を引用したり、因果効果として解釈したりしてはならない。**

---

## 含まれる誤り

### 1. 到達年が未確定の県を never-treated として投入している

`kill_test.py` の `fit()` では、`ARRIVAL` 辞書に載っていない県の `arr` が
`NaN` となり、イベントダミーがすべて 0 になる。エラーも警告も出ないまま、
これらの県は「未処置対照」として推定に入る。

該当 41 県は 1965–75 年の全国まつたけ生産の **94.0%** を保有していた。
広島（284.6 t）、岡山（146.5 t）、京都（138.8 t）、兵庫（106.5 t）はいずれも
到達履歴が未確認であり、未処置ではない。

比較県の選択だけで事後係数の符号が反転する。

### 2. プラシーボが代数的恒等式になっている

4 品目それぞれを処置品目に差し替えた事後係数の合計が厳密にゼロになる
（+0.493 − 0.422 − 0.328 + 0.256 = 0.0000）。県×年固定効果の下では
各品目の偏差が合計ゼロになるためで、独立した偽陽性の証拠ではない。

正しいプラシーボは、まつたけを標本から除いて対照品目同士を比べること。

### 3. 到達年の一律シフトは偽日付検定ではない

`kill_test_robustness.csv` の「到達年 ±2/±3 年ずらし」は、基準年を移動させて
同じイベント系列を再基準化しているだけである。正しくは処置県間で到達年を
入れ替える（`output/firststage/fs_permutations.csv` を参照）。

### 4. leave-one-out が leave-one-out になっていない

`ARRIVAL` 辞書から `pop` しているだけなので、当該県は標本から除去されず
対照群へ移動する。

### 5. 設計書との不一致

`kill_test.py` は pooled TWFE であり、設計に記した stacked DDD / BJS ではない。
また 1983 年を除外すると記しながら補正値を使用している。

| `kill_test_coverage.csv` | 年別カバレッジ。**これは有効**（誤り 1 の根拠となる数値） |

`kill_test_coverage.csv` だけは、処置県が全国生産に占める割合を示す記述統計で
あり、推定を伴わないため有効である。
