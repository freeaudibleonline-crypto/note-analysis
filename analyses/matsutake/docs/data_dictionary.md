## `data/processed/tokuyo_panel_v3.csv`

都道府県別特用林産物生産量、ロング形式。34,639 行。
年 × 47 都道府県 × 品目。1965–2019 年（1996–98 年は原資料が存在しない）。

| 列 | 型 | 説明 |
|---|---|---|
| `year` | int | 西暦年。原資料は暦年（1 月 1 日〜12 月 31 日）ベース |
| `pref` | str | 都道府県名（「県」「府」「都」を除いた正規化形。北海道のみ「北海道」） |
| `item` | str | 品目の正規化名 |
| `item_raw` | str | 原票の見出しそのまま（`乾燥しいたけ`、`くり※１` 等） |
| `raw_value` | str | xlrd が読み取ったセル値の文字列表現。数値セルは float の表現になる(例: 原票の `183` は `183.0`)。値そのものは加工していないが、原票の書式そのままではない |
| `value_raw` | float | 数値として読めた場合の値（1983 年補正**前**） |
| `value` | float | 分析用の値（1983 年補正**後**、ハイフンのゼロ変換後） |
| `status` | str | セルの状態。下表参照 |
| `unit` | str | 原票の単位行の文字列 |
| `regime` | str | その年その品目の公表様式。下表参照 |
| `scale_flag` | str | 尺度断層の検出結果。下表参照 |
| `source_file` | str | 由来する原 XLS のファイル名 |

### `status` の値（9 種）

| 値 | 意味 | `value` |
|---|---|---|
| `num` | 数値が記載されている | その値 |
| `zero_dash` | ハイフン。**全国値が数値である年**なので分析上のゼロと分類 | `0.0` |
| `item_unobserved` | ハイフンだが**全国値もハイフン**。その年その品目は調査されていない | 欠測 |
| `suppressed_x` | `x`。統計法に基づく秘匿 | 欠測 |
| `repaired_x10` | 1983 年の桁ずれと整合的なセルを 10 倍した暫定補正値 | 補正後の値 |
| `not_in_source` | 原票にその県の行が存在しない（沖縄 1965–72 年） | 欠測 |
| `suspect_num` | 全国値と県計が 2% を超えて乖離し、補正規則でも閉じない年の数値 | その値（**要注意**） |
| `gap_w_suppression` | 乖離があるが、秘匿セルの存在で説明可能 | その値 |
| `blank` | 空欄（全国値は数値） | 欠測 |
| `other` | 上記のいずれにも当てはまらない文字列 | 欠測 |

（実データに出現するのは `num`, `zero_dash`, `item_unobserved`, `suspect_num`,
`repaired_x10`, `not_in_source`, `gap_w_suppression`, `suppressed_x`, `blank`
の 9 種。`other` は定義のみで出現しない。）

**ハイフンの解釈は列単位で行っている。** 全国値が数値なら県のハイフンを
**分析上のゼロ**と分類し、全国値がハイフンならその品目は未観測とする。
加算恒等式（全国値＝県計）が成立する年では、この解釈が支持される。
成立しない年（`suspect_num` を含む年）については、この解釈の裏づけがない。

### `regime` の値

| 値 | 意味 |
|---|---|
| `all_listed` | 全 47 県に数値が入っている年（ゼロも `0.0` と表記） |
| `positive_only` | 正値のみ数値、ゼロはハイフンで表記 |
| `unobserved` | その年その品目は未調査 |

同一品目でもゼロの表記法が年次で切り替わる。**ハイフンを正しくゼロへ変換した後
であれば `1[value > 0]` は表記方式に影響されない。** 外延マージンの分析で
実際に問題になるのは、(a) ハイフンを欠測として誤ってパースすること、
(b) `suppressed_x` の扱いである。秘匿県は「生産があるが非公表」なので、
`1[value > 0]` を計算する際に 0 と数えてはならない。

### `scale_flag` の値

| 値 | 意味 |
|---|---|
| （空） | 断層なし |
| `unit_label_change` | 単位ラベル自体が前年から変わった |
| `unmarked_scale_break` | 単位ラベルは不変だが全国値が前年比 20 倍超または 1/20 未満（自動検出） |
| `manual_known_break` | 自動閾値（20 倍）では検出されないが、原票の突き合わせで確認した断層（手動フラグ） |

検出された断層:

| 年 | 品目 | 種別 | 内容 |
|---|---|---|---|
| 1976 | まき | `unit_label_change` | 千束 → 層積 m³ |
| 1985 | まき | `unmarked_scale_break` | ラベル不変のまま約 1,000 倍 |
| 1988 | くり | `unmarked_scale_break` | 647 t → 36,850 t。出典が作物統計（果樹）へ切替 |
| 1973 | くり | `manual_known_break` | 2,837 t → 470 t（手動フラグ） |
| 1988 | くるみ | `manual_known_break` | 100 t → 752 t（手動フラグ） |

`くり` については、遅くとも 2015 年時点で作物統計（果樹）由来の数値に
なっている（原票の注記による）。1988 年の断層がその切替時点かどうかは
原票からは確定できない。

**`まき`・`くり`・`くるみ` は連続系列として扱ってはならない。**
自動閾値は 20 倍で設定しているため、それ未満の断層は検出されない。
新たに品目を使う際は、`tokuyo_itemyear_qa_v3.csv` の `national` 列を
目視で確認することを推奨する。

## `data/processed/tokuyo_itemyear_qa_v3.csv`

年 × 品目の品質管理テーブル。737 行。

| 列 | 説明 |
|---|---|
| `national` / `national_kind` | 原票の全国行の値と種別 |
| `sum_raw` / `sum_repaired` | 県計（補正前 / 補正後） |
| `gap` / `gap_pct` | 全国値 − 県計、およびその比率 |
| `consistent_raw` | **補正前**の県計について、乖離が許容範囲（2% + 1）内なら 1 |
| `consistent_repaired` | **補正後**の県計について同じ判定を行った結果 |
| `repair_rule` | 補正に成功した規則（`decimal` / `neighbor` / 空） |
| `gap_reason` | `suppression`（秘匿で説明可能） / `unresolved` / 空 |
| `n_num` / `n_dash` / `n_x` / `n_absent` | 各状態の県数 |

### 未解決の不整合

| 年 | 品目 | 乖離 | 備考 |
|---|---|---|---|
| 2010–19 | くり | 一貫して 14–24% | 全国値が主産県からの推計値。**対照品目に使用不可** |
| 1976 | 乾しいたけ | −1,000（−8.9%） | 単一県の桁誤りの可能性 |
| 1988 | くり | +8,000 | 出典切替に伴う |
| 1991 | 竹材 | +248（3.8%） | 未特定 |

## `data/processed/timber_pref_species_1960_2013.csv`

樹種別素材生産量、ワイド形式。1960–2013 年 × 47 都道府県 + 全国。単位 千 m³。

列は `year`, `pref`, および 13 の樹種区分（`計`, `針葉樹_計`,
`針葉樹_あかまつ・くろまつ`, `針葉樹_すぎ`, `針葉樹_ひのき`, `針葉樹_もみ・つが`,
`針葉樹_からまつ`, `針葉樹_えぞまつ・とどまつ`, `針葉樹_その他`, `広葉樹_計`,
`広葉樹_なら`, `広葉樹_ぶな`, `広葉樹_その他`）。

**注意点**

- `針葉樹_えぞまつ・とどまつ` の 1978 年以前は `からまつ` を含む（原資料の注記）
- `広葉樹_なら` は 2003 年で系列が終了する（2004 年以降は欠測）
- 2000–01 年に調査方法の変更があり、あかまつ・ならの全国値が他樹種の 4 倍の
  下落幅を示す。**2000 年以降と接続してはならない**

## `output/firststage/fs_sample.csv`

Gate 5 診断の推定標本。950 行（8 県 × 40 年 × 3 樹種 − 欠測 10）。
`event_time`、`event_time_binned`、`arrival`、`arrival_source`、
3 種の固定効果キーを含む。

欠測 10 セルはすべて北海道のひのき（1964, 1970, 1972, 1973, 1975, 1978, 1979,
1982, 1984, 1985 年）。`fs_missing_cells.csv` に位置を記録している。

## `output/matsutake_diagnostic/`

まつたけ診断の最終仕様（確認済み 8 県、1983 年除外、切片あり）の出力。
