# 技術ノート:松くい虫到達を用いた識別が成立しなかった経緯

本ノートは、当初の目的であった因果推定がなぜ成立しなかったかを記録する。
記事本文（`article/note_draft.md`）は一般向けにこの内容を要約している。

---

## 1. 当初の設計

**問い**: 松くい虫（マツ材線虫病）の到達は、マツタケ生産をどれだけ減らしたか。

**設計**: 県ごとの初確認年の差を用いた三重差分。

    asinh または log(1+Y)_{p,j,t}
      = α_{pj} + λ_{pt} + μ_{jt}
        + Σ_h β_h · 1[j = まつたけ] · 1[t − T_p ∈ h] + ε

- `p` 県、`j` 品目、`t` 年、`T_p` 県 `p` の到達年
- 県×年 FE が、県レベルで全品目に等しく効くもの（天候、過疎、採取労働、
  県の林政、報告体制）を吸収する
- 品目×年 FE が全国的な需要ショックを吸収する
- 対照品目はアカマツに依存しない比較候補（くるみ、なめこ、生しいたけ）。
  なお「なめこ」は栽培品を含み、野生採取品ではない（3.1 節参照）

**この設計の主張は「到達年が地域経済と無相関」ではなく、より弱い
「到達タイミングが、県内でまつたけ特有のショックと相関していない」である。**

## 2. 最初の推定における実装上の誤り 5 件

以下はいずれも `archive/invalid_initial_analysis/` に保存されたコードに
含まれていた誤りである。**削除せず保存しているのは、記事中の監査を
再現できるようにするためであり、因果推定に使ってはならない。**

### 誤り 1: 到達年が未確定の県を never-treated として投入した

到達年の辞書に載っていない県は `NaN` となり、イベントダミーがすべて 0 になる。
エラーも警告も出ない。結果としてこれらは「未処置対照」として推定に入った。

**該当 41 県が、1965–75 年の全国まつたけ生産の 94.0% を保有していた。**

| 県 | 1965–75 年平均 | 誤った扱い |
|---|---|---|
| 広島 | 284.6 t | 未処置対照 |
| 岡山 | 146.5 t | 未処置対照 |
| 京都 | 138.8 t | 未処置対照 |
| 兵庫 | 106.5 t | 未処置対照 |
| 岐阜 | 47.9 t | 未処置対照 |

これらの県の到達履歴は確認できていない。**「到達履歴が未確認」は
「未処置」ではない。** 比較県の選択だけで事後係数の符号が反転する。

| 使用県 | 事前平均 | 事後平均 |
|---|---|---|
| 47 県（誤ったコード） | +0.349 | **+0.493** |
| 6 処置県 + 北海道・青森 | +0.209 | +0.229 |
| 6 処置県のみ（恒常的未処置県なし） | +0.618 | **−0.676** |

最後の行は恒常的な未処置県を含まない。pooled TWFE では既処置県が比較に
混入するため解釈不能である。ただし「比較県の選択だけで符号が変わる」ことは示す。

### 誤り 2: プラシーボが代数的恒等式だった

4 品目それぞれを「処置品目」に差し替えたときの事後係数:

    まつたけ    +0.493
    くるみ      −0.422
    なめこ      −0.328
    生しいたけ  +0.256
    ────────────────
    合計        +0.0000

厳密にゼロである。県×年 FE の下では、ある県年における各品目の偏差は
重み付きで合計ゼロになる。ある品目の正の偏差は、他品目の負の偏差として
現れるほかない。**くるみの −0.422 は独立した偽陽性ではない。**

正しいプラシーボは、まつたけを標本から完全に除いて対照品目同士を比べること。

**ただしここに、当初この文書に記した誤りがある。**「正しいプラシーボは
事前 +0.017 / 事後 −0.070 でほぼゼロだった」という記述は、
**誤り 1 が残った 47 県標本でのみ再現される数値であった**。
到達履歴が確認できた 8 県に限定した最終仕様では、プラシーボは対照品目に
強く依存する（下表）。**「推定量は壊れていなかった」という結論は撤回する。**

### 誤り 3: 「到達年をずらす」は偽日付検定ではない

全県一律に +3 年ずらすと、基準年（t−1）が実際の t+2 に移る。同じイベント系列を
再基準化しているだけで、独立した反証にならない。

正しくは処置県間で到達年を**入れ替える**。6 県のうち 1978 年が重複するため
固有の割り当ては 6!/2! = **360 通り**で、全列挙できる（抽出は不要）。

**ただし到達年は緯度・気候・隣接からの伝播で決まるため交換可能ではない。
これは正式な randomization inference ではなく、日付置換による感度診断である。**

### 誤り 4: leave-one-out の実装

到達年の辞書から `pop` しただけなので、当該県は標本から除去されず
**対照群へ移動**していた。誤り 1 と同じ穴である。

### 誤り 5: 設計書と実装の不一致

- 「stacked DDD または BJS 推定を用いる」と設計に記しながら、実際には
  pooled TWFE を回していた。staggered かつ効果が異質な設定では、
  Goodman-Bacon 分解が示すとおり既処置ユニットが比較に混入する。
- 「1983 年は主仕様から除外」と記しながら、補正値を使用していた。

## 3. 誤りを修正した後の結果

### 3.1 まつたけ本体（最終仕様）

`code/04_matsutake_diagnostic.py`。標本は到達履歴が確認できた 8 県のみ
（処置 6 県 + 北海道・青森）、1965–1995 年、1983 年除外、切片あり、
イベント時間 [-8, +10]、N = 959、クラスタ 8、
クラスタ頑健共分散行列の実効階数 7。

| 仕様 | N | 事前平均 (t ≤ −2) | 事後平均 (t ≥ 0) |
|---|---|---|---|
| **本命**: まつたけ 対 くるみ・なめこ・生しいたけ | 959 | **+0.209** | **+0.229** |
| プラシーボ: くるみ 対 なめこ | 480 | −0.358 | +0.147 |
| プラシーボ: くるみ 対 生しいたけ | 480 | −0.092 | −0.218 |
| プラシーボ: なめこ 対 生しいたけ | 480 | +0.265 | −0.364 |
| 本命（対照 = くるみ のみ） | 479 | +0.345 | +0.259 |
| 本命（対照 = なめこ のみ） | 479 | +0.015 | +0.394 |
| 本命（対照 = 生しいたけ のみ） | 479 | +0.266 | +0.036 |

到達年 360 通り全列挙の置換診断では、230 通りが実際以上（比率 0.639）。

**読み取れること**

- 本命の事後平均は正だが、事前平均もほぼ同じ大きさで正である
- プラシーボは対照品目の組み合わせによって +0.147 から −0.364 まで動く
- 対照品目を 1 つに絞ると本命も +0.036 から +0.394 まで動く

**つまり、確認済み 8 県で再構成すると、本命推定にもプラシーボにも
事前差と対照品目依存が残る。** 期待した負の効果は観察されず、
かつ観察された数値を効果として解釈する根拠もない。

対照品目の非平行性については、少なくとも次が寄与している。

- 「なめこ」は栽培品を含み、野生採取品ではない（農林水産省の分類による）。
  したがって「同じ採取労働・同じ天候に晒される非宿主品目」という
  対照の前提を満たしていない
- 「生しいたけ」は施設栽培であり、本来プラシーボであって対照ではない
- 「くるみ」は野生採取品だが水準が小さくゼロが多い

**適切な対照品目（わらび・ぜんまい・たらのめ等の山菜）は、この統計表に
収録されていない。** これは設計上の制約であって、実装で解決できない。

### 3.2 Gate 5 診断（`code/03_firststage_timber.py`）

因果効果を推定する前に、処置が実際に効いているかを確認しようとした。

- 標本: 処置 6 県 + 確認済み未処置 2 県（北海道＝未発生、青森＝2010 年前後）
- アウトカム: あかまつ・くろまつ素材生産量、対照樹種はすぎ・ひのき
- 期間: 1960–1999 年（2000 年以降は木材統計の調査方法変更のため除外）
- N = 950、クラスタ 8

| 指標 | 値 |
|---|---|
| 事前平均（t ≤ −2、端点は t ≤ −10 のビン） | +0.023 |
| 事後 5–9 年 | **−0.177**（= −16.2%） |
| 置換診断（360 通り全列挙） | 63 通りが実際以下 = 0.175 |

**事前平均が小さいことを「平坦性の証拠」と解釈してはならない。** これは相殺の
結果であり、個別には端点ビン（t ≤ −10）の係数が +0.385、95% 信頼区間
[+0.083, +0.686] でゼロを跨いでいない。加えてクラスタは 8 県のみで、
クラスタ頑健共分散行列の実効階数は 7、イベントダミーは 22 本。
**平坦性を評価できる精度がない**というのが正確である。

推定に残る限界:

- pooled TWFE のままであり、stacked / Callaway-Sant'Anna / BJS ではない
- 到達年は交換可能でないため置換は感度診断にすぎない
- 事前に最小意味効果量を定義していないため、−16.2% を「小さい」と評価する
  根拠はない（これは事後判断になる）

## 4. 停止した理由

停止の理由は置換診断の 0.175 ではない。**指標が測りたいものを測っていない**
ことである。

### 4.1 素材生産量は生態学的 first-stage ではない

農林水産省の定義では、山元での供給量を直接調べることが困難なため、
製材工場・合板工場・木材チップ工場への**素材入荷量**をもって素材供給量とする。
したがって

    素材生産量 = f(森林在庫, 需要, 価格, 伐採採算, 工場能力, 被害木の利用)

であり、森林ストックの指標ではない。マツ林が減っても被害木の伐採で
一時的に増えうるし、資源が残っていても坑木需要が消えれば減る。

さらに「あかまつ・くろまつ」は合算値であり、海岸クロマツ林の被害と
内陸アカマツ林（マツタケの宿主）を分離できない。

なお「被害木は法定義務でチップ化されるため salvage が相殺した」という説明を
一時検討したが、これは確認していない。林野庁が示す駆除方法にはくん蒸・破砕・
焼却があり、すべてが工場入荷になるわけではない。また森林病害虫等防除法は
指定区域・期間について伐倒駆除を命じうる制度であって、全被害木の一律伐採義務
ではない。**salvage 相殺は可能な説明の一つにとどまり、本データからは
確認されていない。**

長野のあかまつ素材生産は 1960 年に 439 千 m³、到達年（1981）には既に 90 千 m³
であった。減少の大半は松枯れ到達前に生じている。エネルギー革命に伴う坑木・
薪炭需要の消滅が有力な説明だが、これも本データで検証したわけではない。

### 4.2 県初確認年は県全体の曝露を表さない

「石巻市で 1 本確認された」と「県内アカマツ林の相当部分が枯死した」は別の事象で
ある。処置変数としては薄すぎる。

正しい曝露変数は少なくとも

- 被害材積 ÷ 処置前アカマツ資源量（面積または蓄積）
- 被害発生地とマツタケ発生林分の空間的重複

を要する。県別年次被害量は 2017 年以降しか電子化されておらず、それ以前は
各県の年報等に断片的に存在するにとどまる。処置前のマツ資源量も、森林資源現況
調査は存在するが歴史的な県別パネル化には相当の手作業を要する。

これは追加分析ではなく**新規の資料収集プロジェクト**であり、費用が便益に
見合わないと判断した。

## 5. 結論の書き方

> マツ素材生産には到達後の負方向の変化が見られたが、少数県では実時点の固有性を
> 確認できず、同指標も生態学的 first-stage ではなかった。県初確認年を県全体の
> アカマツ林曝露へ対応づけられないため、因果推定を停止した。

**「松枯れがマツタケを減らした」は否定されていない。この設計では検定できなかった。**

補足として、当初この文書に「正しいプラシーボはほぼゼロで推定量は壊れていない」
と記していたが、これは誤り 1 が残った標本での数値であり、撤回した（3.1 節）。
**この誤りは、誤りを指摘する文書の中で同じ誤りを繰り返していたことになる。**
記録として残す。

## 6. 追試する人へ

このパネルを使って再挑戦する場合、最低限これらが必要になる。

1. **実質的到達年**の定義（初確認ではなく、2 年以上の継続確認、または被害量が
   一定水準に達した年）を、上位 5 産地（広島・岡山・京都・兵庫・岐阜）を含めて確定する
2. **処置前マツ資源による正規化**（被害材積 ÷ アカマツ面積または蓄積）
3. 各コホートに**確認済みの未処置 donor が 3 県以上**
4. 識別可能な処置県が**処置前生産量の 60% 以上**をカバーする
5. **生態学的 first-stage**（被害量の増加、マツ資源の減少）が、素材生産量では
   ない指標で観察できる

加えて、推定側では stacked DDD あるいは異質性頑健推定量、少クラスタ向けの
wild cluster bootstrap、気象統制を用いること。

**2011 年以降を含めてはならない。** 原子力災害対策特別措置法に基づく出荷制限が、
まつたけを含む野生きのこ類と、対照候補（わらび、ぜんまい、たけのこ、原木しいたけ、
なめこ）を同時に、市町村 × 品目という細かい粒度で規制している。県レベルの
パネル設計ではこれを処理できない。
