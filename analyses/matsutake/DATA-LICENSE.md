## 1. 特用林産物生産量パネル

### 原典

農林水産省『特用林産基礎資料』および『農林水産省統計表』。

### 取得経路

山梨県オープンデータカタログ「都道府県別特用林産物生産量」として再配布されていた
年次 XLS ファイル 52 本（1965–1995 年、1999–2019 年）。

### 利用条件

山梨県オープンデータ利用規約に従う。
<https://www.pref.yamanashi.jp/opendata/kiyaku.html>

同規約は商用・非商用を問わず複製・改変・再配布を認めるが、**出典の表示**を
求めている。公開前に最新の規約本文を確認すること（規約は改定されうる）。

取得元 URL・取得日・ファイル 52 本の SHA-256 は `data/raw/CHECKSUMS.md`、
出典一覧は `docs/sources.md` を参照。

### 本リポジトリでの出典表示

> 出典: 農林水産省「特用林産基礎資料」「農林水産省統計表」
> （山梨県オープンデータカタログ「都道府県別特用林産物生産量」経由で取得）。
> 本リポジトリの作成者が加工したものであり、加工の内容について農林水産省および
> 山梨県は関与していない。

### 加工の内容

`data/processed/tokuyo_panel_v3.csv` は原 XLS を機械的に整形したものであり、
以下の加工を行っている。加工の全手順は `code/01_parse_tokuyo.py` に記述されている。

1. 和暦ファイル名から西暦年を復元
2. 都道府県名の正規化（旧字体「沖繩」を含む）
3. 品目名の名寄せ（`乾燥しいたけ`→`乾しいたけ`、`くり※１`→`くり` 等）
4. セル状態の分類（`status` 列。9 種。`docs/data_dictionary.md` 参照）
5. **1983 年ファイルの暫定補正**（後述）

**原セルの読取値は `raw_value` 列に、補正前の数値は `value_raw` 列に保持しており、原 XLS と照合できる。**

### 1983 年の暫定補正について

1983 年のファイルでは、複数品目において県セルの一部が公表値の 1/10 と整合的な
値になっている。全国値と県計を突き合わせると 9 品目で不一致が生じるが、
特定のセルを 10 倍すると加算恒等式が閉じる。

これは **内部整合性による暫定補正であり、原典（紙媒体）と照合して正解と確認した
ものではない**。該当セルは `status = repaired_x10` で識別でき、補正前の値は
`value_raw` 列に保持している。**主分析では 1983 年を除外し、補正値の使用は
感度分析に限ることを推奨する。**

## 2. 樹種別素材生産量パネル

### 原典

農林水産省「木材統計調査 長期累年『木材需給報告書 主要樹種別素材生産量累年統計
都道府県別』」（e-Stat, `statsDataId = 0003234708`）。1960–2013 年、47 都道府県、
13 樹種区分、単位 千 m³。

### 取得方法

e-Stat API (`getStatsData`) 経由。取得コードは `code/00_fetch_estat_timber.py`。
実行には e-Stat のアプリケーション ID（環境変数 `ESTAT_APP_ID`）が必要。
同梱の processed ファイルからすべての解析を再現できるため、
このスクリプトの実行は必須ではない。

### 利用条件

政府統計の総合窓口（e-Stat）利用規約に従う。<https://www.e-stat.go.jp/terms-of-use>
出典表示のうえで自由に利用できる。

### 重要な注意

**素材生産量は森林ストックの測定値ではない。** 農林水産省の定義では、山元での
供給量を直接調べることが困難なため、製材工場・合板工場・木材チップ工場への
**素材入荷量**をもって素材供給量としている。したがってこの系列は森林在庫、需要、
価格、伐採採算、工場の操業状況、被害木の利用可否を合成した商業フローである。

また「あかまつ・くろまつ」は合算値であり、海岸クロマツ林と内陸アカマツ林を
分離できない。定義の出典は農林水産省「木材統計調査の概要」
<https://www.maff.go.jp/j/tokei/kouhyou/mokuzai/gaiyou/index.html>。

`data/processed/timber_pref_species_1960_2013.csv` は、API の JSON 応答を
ワイド形式に整形したのみで、値の加工は行っていない。

## 3. 松くい虫の県別初確認年

各県の公表資料から手作業で収集した。出典は
`output/firststage/fs_sample.csv` の `arrival_source` 列、および
`code/03_firststage_timber.py` の `ARRIVAL_SOURCE` 辞書に個別に記録している。

| 県 | 年 | 出典 |
|---|---|---|
| 宮城 | 1975 | 宮城県公式サイト（石巻市大門崎） |
| 新潟 | 1977 年度 | 新潟県治山課（南魚沼市） |
| 山形 | 1978 | 山形県松くい虫被害対策推進計画（山形市） |
| 山梨 | 1978 | 山梨県公式サイト |
| 長野 | 1981 | 長野県林業総合センター研究報告（木曽郡山口村） |
| 秋田 | 1982 年度 | 秋田県公式サイト（にかほ市・旧象潟町） |

**これらは「県内のどこか一市町村で初めて確認された年」であり、県全体のマツ林が
曝露された時点ではない。** 曝露の代理変数としての妥当性については
`docs/technical_note.md` を、文書の正式名称・URL・閲覧日については
`docs/sources.md` を参照。

未処置として扱った青森県については、県公式ページに 2010 年 1 月に蓬田村で
初確認された旨が記載されている。推定窓（1965–1999 年）の外であるため、
未処置として扱うことに問題はない。

## 5. 品目の分類について

「なめこ」は栽培品を含む（農林水産省「林業産出額」の分類による）。
本リポジトリでは野生採取品として扱わず、**非宿主の比較候補**と位置づけている。
まつたけの対照品目として理想的な野生採取品（わらび・ぜんまい・たらのめ等の
山菜）は、この統計表には収録されていない。
